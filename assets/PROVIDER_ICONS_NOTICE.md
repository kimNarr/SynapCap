[Simple Icons](https://simpleicons.org/) project. The Claude badge uses a
hand-drawn radial burst as a stand-in for the official Claude mark
(`ui/icon.py::_claude_burst_markup`, `docs/assets/provider-claude.svg`) —
swap it for the licensed mark when one is vendored.
