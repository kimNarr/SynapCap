## Part 1 — 디자인 언어

### 원칙

1. **한눈에** — 2초 안에 "얼마나 썼는지" 읽혀야 한다. 큰 숫자, 의미 있는 색, 한 줄 한 지표.
2. **방해하지 않기** — 작업표시줄·Alt+Tab·Dock에는 나타나지 않으며, 펼침·막대·트레이만 중 상황에 맞는 밀도를 고른다.
3. **정직하게** — CLI가 준 값 그대로. 보정·추정 없음. 세 프로바이더 모두 링·탭 툴팁에
   "어느 CLI가 로컬에 기록한 값인지 + 마지막 조회 시각"을 밝힌다. Claude는 화면과 차이가
   날 수 있다는 주의를 덧붙인다.
4. **로컬·프라이빗** — API 키 없음. 진단 보고서에 토큰 미포함. 설정은 로컬에만.
5. **두 OS 한 얼굴** — Windows·macOS가 같은 타이틀바·체크박스·여백. 네이티브 컨트롤 대신 `QPainter`로 직접 그림.
6. **일관되게 고정한다** — 펼침 보기는 384px 고정 폭·가로 한 모델 집중 링으로 제공해 모델별 화면 차이를 없앤다.

### 사용량 스케일 — 색이 곧 경고 단계 (4단계)

`_usage_color(used)` — `ui/widget.py`. 임계값 상수 `USAGE_NOTICE=60` / `USAGE_WARN=75` / `USAGE_CRIT=90`.

| 범위 | 토큰 | 다크 / 라이트 | 의미 | 추가 신호 |
| --- | --- | --- | --- | --- |
| `< 60` | `usage_calm` | `#8087A0` / `#7C8296` | 여유 — 낮은 값이 실제 값과 경쟁하지 않게 무채색으로 죽임 | — |
| `60–74` | `usage_ok` | `#89B4FA` / `#1857C9` | 주목 (급하진 않음) | — |
| `75–89` | `usage_warn` | `#FAB387` / `#C2410C` | 경고 (앰버 / 번트 오렌지) | `%` 굵기 700 |
| `>= 90` | `usage_crit` | `#F38BA8` / `#B42352` | 위험 | 굵기 700 + `▲` 프리픽스 |

진행 막대 채움 색과 `%` 글자 색 둘 다 이 함수로 결정된다. `usage_alert_threshold` 기본값 90과 정렬.

**컴팩트 바 예외** (`_compact_usage_color`): `< 75`(WARN 미만)이면 흰색 `#F8FAFC`, 이상이면 위 스케일.
두 사용량 창은 `76 / 44%`로 표기한다. 슬래시 양쪽의 여백으로 두 수치를 분명히 분리해
분수처럼 붙어 보이지 않게 한다. 두 값 중 높은 사용률 하나를 기준으로 색과 굵기를 정해
`%`가 중복되거나 한 줄 안에서 색이 갈라지는 문제를 없앤다. 각 프로바이더는 카드·테두리 없이
`아이콘 + 수치`의 평면 그룹으로 두고, 충분한 여백만으로 구분한다. 컴팩트 막대에서는 앱 로고·프로바이더·창 제어 사이 세로선을 모두 제거한다.
기본 수치는 `Medium(500)`, 위험은 `700`으로 올려 색상 외에도 단계가 읽히게 한다. 위험 상태도 글자 크기는
키우지 않아 막대 높이와 숫자 정렬이 흔들리지 않는다.
값 라벨은 최대 자릿수(`\d+`→2자리) 기준으로 폭을 예약한다.

즉시 툴팁은 OS가 어두운 네이티브 배경을 강제하는 경우에도 읽히도록 다크·라이트 모두
`ToolTipBase=#171A21`, `ToolTipText=#F8FAFC`의 고대비 조합을 사용한다.

### 타이포그래피

- 폰트: Windows `Segoe UI`, macOS `-apple-system`, fallback `sans-serif`.
- 고정 스케일 (`FIXED_WIDGET_PRESET`, `ui/widget.py`) — 펼침 폭 384px, 기준 수치 11px.

| 역할 | 공식 | 13px 기준 |
| --- | --- | --- |
| 타이틀 | `font + 2` | 15 |
| 프로바이더 이름 | `font + 1` | 14 |
| 사용량 `%` | `font` | 13 |
| 배지 | `max(9, font − 1)` | 12 |
| 리셋·표식 | `max(9, font − 2)` | 11 |
| 소형 링 지름 | `max(22, font + 8)` | 22 |

- **굵기 위계** (`_set_label_font`은 `400 / 600 / 700` 세 단계):

  | 요소 | 굵기 | 이유 |
  | --- | --- | --- |
  | 프로바이더 이름 | `700` Bold | 카드 앵커 |
  | 사용량 `%` (< 75) | `600` DemiBold (bold 옵션 off면 `400`) | 데이터지만 조용히 |
  | 사용량 `%` (≥ 75, 경고·위험) | `700` Bold + `▲`(≥90) | 굵기 자체가 "높아지는 중" 신호 |
  | `5h` / `7d` 기간 라벨 | `600` DemiBold, `ink_dim`, 테두리 없음 | 행 라벨 — 버튼처럼 안 보이게 |
  | 리셋 카운트다운 | `400` Regular · `#8087A0` · `val_size − 2` | 보조 정보 |

  → 볼드는 "여기 봐"(카드 이름 + 높아진 값)에만. 나머지는 차분하게.
- 수치는 항상 `tabular-nums` 의도.

### 레이아웃

| 요소 | 반경 | 테두리 |
| --- | --- | --- |
| 위젯 프레임 | 6 | 2px `#4A5266` |
| 내부 프로바이더 프레임 | 6 | 1px `#272C38` |
| 배지·표식·메트릭 행 | 5 | none |

- 컴팩트 바: 프로바이더별 `아이콘 + 5h·7d 값` 한 줄 카드. 모델명은 아이콘과 툴팁으로
  확인하므로 막대 안에는 반복 표시하지 않는다. 카드 내부 좌우 여백
  `max(4, font × 0.34)`, 아이콘과 수치는 최소 `6px`, 카드 사이 `max(5, font × 0.4)`.
  프로바이더 사이 구분선은 쓰지 않는다.

- 프레임 여백 `12 / 14 / 12 / 12`, 요소 간격 `10`.
- 링 행 내부 간격 `max(6, val_size × 0.45)`.
- 위젯 폭: 펼침 보기 384px 고정. 컴팩트 바만 표시 내용에 맞춰 폭을 조절한다.
- 엣지 스냅 거리 `EDGE_SNAP_DISTANCE = 48`.

### 표시 모드와 트레이 헤드라인

- 펼침·막대는 `QScreen.availableGeometry()`를 기준으로 위치를 보정해 작업표시줄·Dock과 겹치지 않는다.
- 두 창 모드의 마지막 위치는 각각 저장한다. 트레이만 모드에서 아이콘을 클릭하면 마지막으로 사용한
  펼침 또는 막대 모드와 그 위치를 복원한다.
- 트레이 아이콘은 조회 가능한 모든 한도 중 가장 높은 사용률을 정수로 표시하며, 링과 같은 4단계
  상태색을 사용한다. 조회 전이나 모두 오류인 경우에는 기본 앱 아이콘으로 돌아간다.

```
│             ◯ 28%         ◯ 61%        │
│            6d 20h        4d 12h        │
└───────────────────────────────┘
```

- 각 카드: 상단 `SESSION`/`WEEKLY` · 중앙 링의 `%` · 하단 `_condensed_reset` 순서다. 세 요소 모두
  중앙 정렬하며, 기간 표식은 별도로 표시하지 않는다. **읽는 순서는 링의 `%`가 헤드라인** —
  `SESSION`/`WEEKLY`(`ink_mid` · `font−2`)와 리셋 카운트다운(`ink_dim` · `400` · `font−2`)은
  조용한 보조 라벨로 둔다. 사용량 상세와 갱신 시각은 링 및 새로고침 버튼 툴팁으로 제공한다.
- **갱신 캡션**은 별도 행을 두지 않고 새로고침 버튼 툴팁에 넣는다.
  `_freshness_caption` / `_update_freshness_caption`.
- 가로 한 모델 집중 링은 유일한 펼침 구조다. 상단 탭에 모든 프로바이더의 요약 사용량을 표시하고,
  선택한 프로바이더 카드 하나에서 `5h`·`7d` 대형 링을 나란히 표시한다. 탭은 작은 모델명과
  큰 사용량 요약의 두 단계 글자 위계를 쓰며, 선택 탭만 accent 테두리를 사용한다.
  집중 보기 전용 `focus_tab_*`·`focus_metric_*` 토큰으로 바탕을 분리한다.

### P1 — 읽기를 방해하는 문제

#### I-01 · 낮은 사용률 막대가 안 보임 — 적용됨

**현상**: `6d 22h ▏3%` 처럼 사용률이 낮으면 `QProgressBar::chunk`가 실선 한 가닥이라
"빈 막대 / 렌더 깨짐"으로 읽힌다.

**적용**: `QProgressBar` → `UsageBar`(`QWidget` + `paintEvent`)로 교체.
`used > 0`이면 채움 폭 `max(3px, 비율)`, `used = 0`이면 채움 없음.
위젯에 `objectName="usageBar"`, `usage_used`, `fill_width` 노출(테스트가 조회).
`findChild(QProgressBar)`를 쓰던 테스트 다수 갱신 완료.

---

#### I-02 · 한 행에 숫자 두 개가 경쟁 — 적용됨

**현상**: `3h 44m`(리셋까지 남은 시간)과 `16%`(사용량)이 비슷한 크기·색 무게로 나란히 있어
한눈에 무엇이 헤드라인인지 불명확하다.

**적용**: `reset_label`을 `#8087A0` · `max(9, val_size − 2)` · `00d 00h` 기준 고정폭으로 강등.
`%`는 오른쪽 고정 열에서 스케일 색 + 굵기 위계로 가장 먼저 읽히게. (아래 굵기 위계 참고)

---

#### I-03 · 경고 단계가 색으로만 구분됨 (접근성) — 적용됨

**현상**: 경계가 색 변화로만 표현된다. 색각 이상 사용자는 구분이 어렵다.

**적용**: `75–89`(경고)는 `value_label` 굵게(`700`), `>= 90`(위험)은 `▲ 92%`처럼 삼각형
프리픽스 + 굵게. 이 신호는 펼침 글꼴 굵기 설정과 무관하게 유지.
`test_warning_and_critical_values_have_non_color_signals`로 고정.
2차 개선(외부 리뷰 반영): 스케일을 4단계로 재조정하고 `< 60` 구간을 무채색 `usage_calm`으로
죽여, 낮은 값이 실제 값과 시각적으로 경쟁하지 않게 함. 임계 `USAGE_WARN` 60→75,
`USAGE_CRIT`(▲) 80→90.
남은 아이디어: 막대 채움 `>= 90` 상단 하이라이트, 세그먼트 스트라이프(시안 참고).

#### I-07 · 언어 혼용 (리셋만 영어) — 결정됨(B)

리셋 표기는 **영어 축약 유지**(`3h 44m` / `6d 22h`)로 결정. `_condensed_reset`이

#### I-08 · 카드 여백 불균형 — 적용됨

**적용**: 프리셋에 `card_gap`(카드 사이, 4/5·5/7·7/9) 추가 → `cards_layout.setSpacing`.
`card_spacing`(이름→행)은 줄이고 `window_spacing`(행 사이)은 늘림.
카드 상/하 패딩은 `card_padding × 0.72`로 좌우와 분리(수직만 축소).
결과: 카드 내부 간격(이름→행 ~7px, 행 사이 ~9px)보다 카드 사이 간격(~29px)이
훨씬 커서 각 프로바이더가 한 덩어리로 읽힌다. 배지 높이에 따른 이름 "halo"는 유지(의도).

---

#### I-09 · 경고색 대비 약함 — 적용됨

**적용**: `_usage_color`의 60–79 색을 `#F9E2AF`(파스텔 옐로) → `#FAB387`(peach)로.
파랑 → peach → 핑크의 자연스러운 램프가 되고, 어두운 바탕에서 확실히 뜬다.
`waiting` 배지(`한도 정보 없음`)는 다른 의미(경고 아님, 정보)라 옐로 유지.
`test_usage_scale_uses_blue_peach_red`로 고정.

---

#### I-17 · 리셋 열 고정폭이 한국어 상태 문구를 자름 (I-05의 부작용) — 적용됨

**적용**: `_condensed_reset`이 상태 문구를 짧게 매핑 — `초기화 확인 중` → `확인 중`,
`리셋 시각 미상`/`""` → `미상` (`_RESET_STATUS_SHORT`). 기간 표식과 리셋 시간은 읽는 흐름을
방해하지 않도록 툴팁을 표시하지 않으며, 카운트다운 표기·열 폭은 그대로 유지한다.
`test_stale_reset_shows_short_label_without_tooltip`, `test_missing_reset_is_shown_without_tooltip`로 고정.
